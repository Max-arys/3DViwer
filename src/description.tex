\section{О программе}
3DViewer v2.0 - приложение для просмотра 3D моделей.

\section{Функциональность}
\begin{itemize}
  \item Загрузка OBJ файлов
  \item Вращение, масштабирование и перемещение модели
  \item Настройка отображения (цвет, тип линий, тип вершин)
  \item Сохранение настроек
\end{itemize}

\section{Установка}
\begin{verbatim}
make install
\end{verbatim}

\section{Запуск}
\begin{verbatim}
make run
\end{verbatim}

\section{Тестирование}
\begin{verbatim}
make test
